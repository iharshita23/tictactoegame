# tictactoegame

## Description
Tic Tac Toe Console Game is a simple, console-based implementation of the classic Tic Tac Toe game developed in Java. This project serves as an introductory learning exercise to understand fundamental programming concepts such as arrays, loops, conditionals, and user input handling. Players take turns to place their marks on a 3x3 grid, and the game detects win conditions and invalid moves, providing a basic yet interactive gaming experience directly in the terminal.
